# 做出同系列纸雕质感与生命力，而不是把一张扁图旋转

## 1. 决定画什么（结构 + 光 + 动）

每张卡由四件东西构成，缺一不可：

- **棉纸底图 + 凹窗远景**：5:7 竖幅（`940×1316`）、奶白棉纸边框 + 压纹角花 + 中央凹进的拱窗/圆窗远景（深色夜空、暮色花园或橱窗能把前景纸层衬出来）。
- **8–13 个真正独立的前景纸层**：云朵、主视觉（蛋糕/礼盒/月亮）、花枝、丝带、角标星星、底部徽章分别出图，按 `lift` 从 `0.010` 到 `0.028` 错开高度，且有局部破出窗框形成真实遮挡。
- **局部烫金 + 冷压浮雕**：金色（色相 30–55° 的暖金，如 `#CFA44E` / `#E6C97E`）只用在月亮、星芒、丝带金边、蝴蝶结、礼盒缎带；`bake_card.py` 会把这些区域烘焙成真实金属反光，纸面保持柔和哑光。
- **活起来的感觉**：一处呼吸/闪烁的暖光（`glow`）、窗内随鼠标微风飘动的粒子（`particles`: `snow` / `gold` / `petals`）、以及底图上能随风轻摆、落地打招呼、点按触发星火的部件（`live`）。

## 2. 拆图与 AI 出图规则

- **底图**：正面平视、铺满整张画布；留出纸纹、双层压纹边框与窗内远景。不要画卡片外轮廓、文字、歪斜透视、投影、镜面高光或前景大元素。
- **前景元素**：用纯品红 `#FF00FF` 平底逐个出图（避免模型把灰白棋盘格画进 RGB），再用随包脚本干净抠图去杂边：
  - 品红底：`python3 "$SKILL_DIR/scripts/cutout_element.py" raw.png ./my-card/art/elements/item.webp`
  - 棋盘格底：`python3 "$SKILL_DIR/scripts/cutout_element.py" raw.png ./my-card/art/elements/item.webp --mode checker`
- **参考出图提示**：「奶白棉纸上的分层纸雕贺卡，正面扫描视角，均匀漫射光，无字无投影无透视；主题为【生日花园】。底图只画双线压纹边框和拱形窗内暮色远景；前景元素分别在 `#FF00FF` 纯品红底上单独出图。暖金色 `#CFA44E/#E6C97E` 仅限丝带金边、星星与烛火。」

## 3. 烘焙棉纸浮雕与烫金贴图

换图后**必须重新烘焙**，绝不能把旧冬夜月光的法线贴图套在新图上：

```sh
python3 "$SKILL_DIR/scripts/bake_card.py" ./my-card --tooth 1.5 --relief 1.15
```

脚本会把底图和 `art/layout.json` 中每个 `items[]` 烘焙出 `*-normal.webp`（冷压棉纸颗粒 + 颜料浮雕边 + 沿轮廓的笔触法线）与 `*-surface.webp`（G=粗糙度、B=金属度），并自动写入 `art/baked/manifest.json`。若临时跳过烘焙，可在 `art/layout.json` 顶层设 `"baked": false` 以纯哑光纸预览。

## 4. 在 `art/layout.json` 里让卡片活起来

在生成目录内修改 `art/layout.json`（不改 Skill 安装包）：

- `base` / `cover`：`cover-base.webp` 是不含前景的底纸；`cover.webp` 是平面合成，用于加载期和无 WebGL 后备，换主题时同步更新。
- `items[]`：`{ id, src, box: [x, y, w], lift, bob? }`。`lift` 建议 0.010–0.028 逐层拉开；悬挂饰物（铃铛、吊坠、星芒）加 `"bob": 0.0012`–`0.0018` 产生轻浮呼吸感。
- `motifs[]`：左内页与封底压印徽章（默认复用底部徽章与星芒），留空 `[]` 则纯纸页；`backLine` 自定义封底落款。
- `winterEffects`：非冬日主题设为 `false`（关闭默认的夜空雪幕与冬夜灯位）。
- `glow`：任意主题的暖光源（烛火、灯笼、窗灯），如 `{"at": [470, 466], "color": "#ffd378", "size": 0.56, "intensity": 0.85, "flicker": true}`。
- `particles`：窗内漂浮粒子，支持 `"kind": "snow" | "gold" | "petals"`，如 `{"kind": "gold", "area": [210, 150, 520, 610], "count": 38, "size": 0.15}`，随鼠标扫过的微风飘移。
- `live`：底图局部着色器微动（像素坐标基于 `size`）：
  - `movers`：用 `pivot` + `tip`/`width`（枝叶、烟缕）或 `area`（灯焰、花团）定义 `sway` / `flicker` / `breathe` / `wind` / `kick`；
  - `greet`：卡片落地后自动轻晃打招呼的部件列表。

## 5. 四个状态验收

1. **正面**：双层棉纸颗粒与笔触质感明显，烫金呈现暖香槟金而非发黑暗铜，窗景与前景对齐无白边。
2. **滑过与侧转**：鼠标滑过时指针灯在烫金和前景层上扫出清晰高光（不把纯纸面洗白），微风吹动窗内粒子与枝叶；按住拖拽 3/4 侧看时，能看到真实纸层厚度与层间投影，松手带惯性滑行。
3. **点击翻开与合上**：点击封面任意处或底部图标直接翻开贺卡，展开时伴随纸面弯曲与金色星火；再点左侧页或底部图标合上。
4. **内页与纯本地**：左页有压印徽章，右页三槽手写文字完整清晰可读（390px 手机屏不溢出、可键盘访问）；浏览器 Network 全为同源本地资源，无任何外链请求或报错。
